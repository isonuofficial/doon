# Doon Valley — Indian Restaurant & Bar • Kraków

Official luxury restaurant & online food ordering web application for **Doon Valley — Indian Restaurant & Bar (100% Halal)** located at **ul. Zwierzyniecka, 31-103 Kraków, Poland** (near Wawel Castle).

## Key Features
- **Obsidian Black & Royal Gold Minimal Luxury UI** inspired by `grillvora.framer.website`
- **Bilingual (`EN` / `PL`) Experience** with instant language switching
- **Complete 123-Dish Authentic Menu** across 11 numbered culinary chapters (`01 / ON THE MENU` to `11 / ON THE MENU`)
- **Interactive Dish Customizer** (Spice level, dry/gravy style, royal accompaniments, chef notes)
- **Full Checkout Flow** supporting **Cash on Delivery (COD)**, **Card Terminal on Delivery**, and **BLIK / Przelewy24**
- **Customer Account & Order History Modal** (Sign In / Log Out, saved Kraków addresses, phone number, past order history)
- **Order Confirmation Pop-up Toast & 5-Stage Live Order Radar**

## Quick Start

```bash
npm install
npm run dev
```
